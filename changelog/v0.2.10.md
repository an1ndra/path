# v0.2.10

Gemini streaming now supports tool calls.

## Fixed

- **Gemini SSE streaming translates `functionCall` parts into OpenAI `tool_calls` deltas.**
  Agent clients such as Pi can execute tools instead of receiving an empty assistant
  message and stopping.
- **Final text is no longer dropped when a Gemini event carries both text and
  `finishReason`.** The text chunk is emitted before the finish chunk.

The non-streaming path already translated tool calls; this brings streaming to parity.
