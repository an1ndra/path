# v0.2.11

Request IDs on failed calls.

## Added

- Usage records now store the gateway `X-Request-Id` on successes, cache hits and errors.
- `/admin/usage` and `/v1/usage` expose `request_id`.
- The dashboard **Recent failures** table falls back to the gateway request id when the
  upstream provider did not return its own request id.

## Fixed

- Failed calls no longer show `—` in the Request id column.
